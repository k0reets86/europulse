# EPV3 Editorial Spec

## Goal

`EPV3` должен выпускать качественные новостные материалы для EuroPulse в схеме `DE-first`.

Цель не в том, чтобы "быстро пропустить" материал по pipeline, а в том, чтобы:

- понять реальный смысл исходного текста;
- усилить фактуру при необходимости;
- собрать сильный немецкий мастер;
- затем выпустить качественные `UK/EN` переводы;
- только после этого вести материал к публикации.

## Core Writing Rules

- newsroom-style, а не канцелярит;
- короткий, сильный, точный заголовок;
- лид ровно из 2 предложений;
- начало должно сразу раскрывать проблему, изменение или главное последствие;
- текст должен быть живым, ясным, современным;
- без копирования синтаксиса первоисточника;
- без вымышленных фактов;
- без служебных блоков вроде `Почему это важно`, `Контекст`, `Что дальше`;
- структура должна ощущаться как нормальная статья сильного цифрового медиа.

## Language Rules

- любой вход сначала нормализуется в `DE`;
- `UK/EN` создаются только после полного завершения `DE`;
- если исходник не немецкий, перевод в `DE` является только первым техническим шагом;
- после первичного перевода текст всё равно должен пройти полный немецкий editorial/rewrite cycle.

## Quality Rules

- слабый материал нельзя автоматически выбрасывать только из-за недостатка фактуры;
- сначала материал надо попытаться усилить через дополнительные релевантные источники;
- если исходная картинка релевантна, её нужно сохранить приоритетно;
- если медиа нестабильно по URL, приоритетом остаётся локальный импорт/зеркалирование, а не случайная замена.

## Citation Rules

- прямая речь требует понятной атрибуции;
- ссылка в тексте должна вести на первоисточник или действительно опорный источник;
- если используется информация из нескольких источников, это должно быть корректно отражено в source dossier и при необходимости в тексте.

## SEO Rules

До `publish_ready` должны существовать и быть валидны:

- headline;
- slug;
- excerpt/meta description;
- ключевые фразы;
- featured media;
- корректные language versions.

`100/100` не может быть номинальным. Полная готовность означает, что материал действительно publish-grade.
